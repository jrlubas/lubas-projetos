# Lubas Projetos

Site institucional de engenharia estrutural — projetos de concreto, aço, fundações e obras especiais, com expertise em metrô, pontes e infraestrutura urbana.

## Tecnologias

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Como rodar localmente

Pré-requisito: Node.js e npm instalados ([instalar com nvm](https://github.com/nvm-sh/nvm#installing-and-updating)).

```sh
npm i
npm run dev
```

## Build de produção

```sh
npm run build
```

Isso gera a pasta `dist/` com os arquivos estáticos, prontos para deploy em qualquer host (Vercel, Netlify, VPS próprio, etc.).
